# Connection frame: "Today:" summary rolls over at midnight

**Goal** — The Connection frame's `Today: …` summary always describes the current local calendar day. Today it is recomputed only when a Link log line is written, so after a quiet night it keeps showing an earlier day's recoveries (observed: "Today: 1 recovery — Acquisition restart 1 · longest gap 64 s" still on screen three weeks after the 2026-10-30 recovery). Afterwards it switches to the new day's summary within one second of local midnight, with no Link event needed.

**Skills** — none.

- `src/ibl/linklog.py` — add the pure function `local_day(now)`; `LinkLog.summary` uses it.
- `src/ibl/mainwindow.py` — remember which day the Connection frame was drawn for; re-draw it from the existing 500 ms `_link_timer` when the day changes.
- `tests/test_linklog.py` — unit test for `local_day`.
- `tests/test_window_linklog.py` — window test: summary rolls over at midnight with no Link event.

2. `src/ibl/linklog.py` — add a module-level function directly under `_local`:
   ```python
   def local_day(now: float) -> str:
       """The operator's calendar day for `now`, as `YYYY-MM-DD` (the prefix of every log line)."""
       return f"{_local(now):%Y-%m-%d}"
   ```
   In `LinkLog.summary`, replace `today = f"{local:%Y-%m-%d} "` with `today = f"{local_day(now)} "`. Leave the rest of `summary` unchanged. `local_day` is pure (no Qt, takes `now`, no file access) because the window must not do its own date arithmetic (AGENTS.md rule 1) and the window's day check and `summary` must agree on what "today" is.

3. `tests/test_window_linklog.py` — write first, watch it fail. Add `import datetime as _dt` and `from ibl.linklog import local_day`. New test `test_summary_rolls_over_at_midnight_without_a_link_event(window, clock)`:
   ```python
   label = window.settings_panel.lbl_link_summary
   window._log("RECOVERED", step="Acquisition restart", gap_s=64)
   assert label.text() == "Today: 1 recovery — Acquisition restart 1 · longest gap 64 s"
   before = local_day(clock.t)
   local = _dt.datetime.fromtimestamp(clock.t, tz=_dt.UTC).astimezone()
   clock.t = (local + _dt.timedelta(days=1)).replace(hour=1, minute=0, second=0, microsecond=0).timestamp()
   assert local_day(clock.t) != before                      # the clock really is on the next day
   qtbot.waitUntil(lambda: label.text() == "Today: no recoveries", timeout=2000)
   rows = [window.settings_panel.lst_link_events.item(i).text()
           for i in range(window.settings_panel.lst_link_events.count())]
   assert any("RECOVERED  Acquisition restart · gap 64 s" in r for r in rows)   # history list untouched
   ```
   Add `qtbot` to the test's parameters. Do not call any window method after moving the clock: the real 500 ms `_link_timer` must make the change, which is the behaviour under test. (`hour=1` keeps the target on the next day even if a DST change falls overnight.)

4. `src/ibl/mainwindow.py`, `MainWindow.__init__` — in the block of state fields (after `self._link_wanted = False`, before `_build_ui()` and before the `_log("APP_START", …)` call), add:

   Import `local_day` alongside `LinkLog`: `from .linklog import LinkLog, local_day`.

5. `src/ibl/mainwindow.py`, `_refresh_connection_frame` — read the clock once and remember the day:
   ```python
   def _refresh_connection_frame(self) -> None:
       now = self._now()
       self._connection_frame_day = local_day(now)
       self.settings_panel.show_connection(
           self.linklog.summary(now), self.linklog.recent(CONNECTION_FRAME_EVENTS))
   ```

6. `src/ibl/mainwindow.py` — new method directly below `_refresh_connection_frame`:
   ```python
   def _refresh_connection_frame_on_new_day(self) -> None:
       """The summary says "Today"; redraw it when the local day changes even if the Link is quiet."""
       if local_day(self._now()) != self._connection_frame_day:
           self._refresh_connection_frame()
   ```
   It must re-read the Link log **only** when the day has changed, not on every tick: the timer fires every 500 ms for weeks and the month file grows forever.

   Do not put the check inside `_render_link`; that method is reserved for the dot and status line (AGENTS.md rule 3). Do not add a new QTimer.
